# AC without LEM

This repository contains a formalization of a model of dependent type theory on the quasi topos of separated presheaves on 0 < 1.
The model inherits choice and resizing from the meta theory but does not satisfy excluded middle.
For more details see the comments in the beginning of the formalization.

A more general version of this construction for an arbitrary well-order and formalization in Rocq was given independently by [Sewon Park][paper/Park].

[paper/Park]:
  https://arxiv.org/abs/2610.37498
  "Global Choice without Excluded Middle in Dependent Type Theory"
